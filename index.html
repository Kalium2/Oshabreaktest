OSHA Enforcement Search

Establishments, inspections, violations, and accidents, served live from the U.S. Department of Labor OSHA enforcement API.

API connection

Data comes only from the DOL Open Data Portal OSHA datasets (apiprod.dol.gov/v4). You need a free API key from dataportal.dol.gov. The key is kept in this browser only.

Finds establishments by name and location from OSHA inspection records, grouped into one entry per site.

Details
Source: U.S. Department of Labor, Occupational Safety and Health Administration enforcement data, via the DOL Open Data Portal API. This site shows OSHA data only and is not affiliated with DOL or OSHA.
